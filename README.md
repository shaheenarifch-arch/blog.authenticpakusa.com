# blog.authenticpakusa.com
Authentic Pak USA blog (blog.authenticpakusa.com), published by seo-controller.

## How this site works
- Published with GitHub Pages from `main` (root) at https://blog.authenticpakusa.com (see `CNAME`).
- Articles are written into `blog/` by the blog bot in [seo-controller](https://github.com/shaheenarifch-arch/seo-controller) (site entry `blog.authenticpakusa.com` in `sites.json`).
- DNS (GoDaddy): CNAME record `blog` → `shaheenarifch-arch.github.io`. Help: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
- `google77d0e4245e3633a5.html` is the Google Search Console verification file — do not delete.
